# 6.2.0

## Python 3.14 plugin host

This release moves OpenAI completion to Sublime Text's built-in Python 3.14
plugin host.

- Sublime Text build 4205 or newer is required.
- Runtime libraries are installed for the Python 3.14 host.
- The native `llm_runner` bridge moves to its CPython 3.14 release line.
- Sublime Text builds 4050–4204 remain on OpenAI completion 6.1.0 through
  Package Control.
