# 6.0.0

## tldr;

Well. This escalated quickly.

What used to be "yeah yeah Claude/Gemini later probably maybe eventually" is now actually done. The plugin now speaks not only OpenAI-ish `/chat/completions`, but the native APIs too: OpenAI Responses, Anthropic Messages and Google Gemini `generateContent`.

## Disclaimer

- Antrophic and Google have been tested only by e2e tests on rust dep side. But the tests are thorough. So if it blows -- raise an issue with logs -- codex will fix it next time.
- Rust dep ci/cd release pipeline became broken, codex fixed it somehow but at cost of loosing arm7 and some other wierd arch on linux. So if you one of those who are using them -- sorry about that, again, issue, logs, codex will fix it later.

## What actually landed

1. **Anthropic support is done.**
    - Native Messages API.
    - Streaming.
    - Tool calling.
    - Parallel tool calls in a single model turn.
2. **Google Gemini support is done.**
    - Native Gemini API.
    - Streaming.
    - Tool calling.
    - Proper handling of Gemini-specific content parts instead of pretending they're just OpenAI with extra trauma.
3. **OpenAI Responses API support is done properly.**
    - This is now the proper OpenAI-native path.
    - Tool calling works there too, including multiple tool calls per turn.
4. **Legacy `/chat/completions` did not get thrown under the bus.**
    - OpenAI-compatible providers are still supported.
    - Stream parsing is more tolerant to providers that emit cursed partial JSON in SSE chunks, because apparently writing valid JSON is a premium feature now.
5. **The Rust core and Sublime wrapper now speak one sane internal model instead of a pile of provider-specific accidents.**
    - Which means less glue code.
    - Less weird state.
    - Less "this one provider is special" branching.

## Minor collateral damage

- Old README copium about "no more connectors will be added here" has been removed, because, well, that aged beautifully.
- The settings docs were updated to reflect the provider matrix that now actually exists in reality.
