# 6.3.0

## Shared Markdown chat UI

Chat output now uses the bundled `sublime-chat-ui` presentation and Chat
Markdown syntax.

- Questions, selections, answers, and other chat roles are rendered as stable,
  hard-bounded Markdown sections while responses stream.
- Configure `fold_sections` with role names such as `Question` and `Answer` to
  fold those sections automatically. Manual fold choices remain local to each
  chat view during subsequent updates.
- Live section updates now repair partial or shifted fold geometry instead of
  leaving the tail of a long response exposed.
- Click an absolute local Markdown file link in a chat transcript to open the
  file in Sublime Text, including encoded line and column positions.

This release keeps the Python 3.14 runtime and requires Sublime Text build 4205
or newer, as introduced in 6.2.0.
